# Student Management

A React application for managing student profiles. 

## Features
- View student details and profiles
- Simple and responsive UI built with React

## Prerequisites
- Node.js installed

## Getting Started

Follow these instructions to run the project locally.

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   Once the server starts, it will provide a local URL (e.g., `http://localhost:5173/`). Open this URL in your web browser to view the application.

## Technologies Used
- React
- Vite
- CSS
